ARTVAULT — WELCOME TO ASISH (SEPARATE HTML/CSS/JAVASCRIPT FILES)

FILES
-----
index.html     Website structure
style.css      Design, colours, layout and animations
script.js      Enter button interaction
anime-bg.jpg   Add your own licensed anime-style background image here

HOW TO RUN
----------
1. Keep index.html, style.css and script.js in the same folder.
2. Add an image named anime-bg.jpg to this same folder.
3. Open index.html in a browser, or open the folder in VS Code and use the Live Server extension.

IMPORTANT
---------
This is the static welcome-page starter only. The login/register links are placeholders.
Real user accounts, secure passwords, image uploads, comments, admin tools and database
storage are not included yet. Those will require a backend and database.

The full project can later be migrated into the planned Next.js + Java Spring Boot
architecture. This version is deliberately plain HTML, CSS and JavaScript so the files
are separate and easy to understand.
